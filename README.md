# Saint-Gilles parcelle par parcelle

Carte interactive des parcelles de Saint-Gilles (Bruxelles) : bruit, pollution, sol, inondation, bâti, proximités, permis d'urbanisme et indicateurs de quartier.

Sources (open data) : UrbIS (paradigm.brussels), Bruxelles Environnement, Bruxelles Mobilité, urban.brussels (Nova), IBSA – Monitoring des quartiers.
